001 | Core 4-tuple agent abstraction - Implement the AgentTuple dataclass with (Instruction, Context, Tools, Model) fields. Create an AgentFactory that instantiates executable sub-agents from tuples. Each sub-agent runs in isolation with only its assigned context and tools. Include a base SubAgent class with execute() method that takes the tuple, builds a prompt from Instruction+Context, calls the Model with available Tools, and returns structured observations (result_summary, artifacts, error_logs).

002 | Orchestrator with Delegate and Finish - Build the central Orchestrator class that never executes environment actions directly. It has exactly two system actions: Delegate(Phi) which spawns a sub-agent from a 4-tuple and collects its observation, and Finish(y) which terminates with a final answer. The orchestrator maintains a state history of all delegations and observations. It uses an LLM to decide at each step whether to Delegate (and with what tuple) or Finish. Implement the state transition function that integrates returned observations.

003 | Dynamic context curation and tool selection - Implement the context routing system where the orchestrator curates task-relevant context for each sub-agent, filtering out distracting information. Build a ToolRegistry that manages available tools (web_search, code_execute, file_read, calculator, etc.) and allows the orchestrator to select subsets per subtask. The orchestrator should analyze the subtask requirements and dynamically choose which tools and how much context each sub-agent needs.

004 | Cost-aware model routing - Implement the model selection strategy where the orchestrator picks cheap models (glm-4-flash) for simple subtasks and expensive models (glm-4.7) for complex ones. Define a CostTracker that monitors token usage and monetary cost per delegation. Implement the cost-performance trade-off parameter lambda that controls how aggressively the system optimizes for cost vs accuracy. Include a ModelRegistry with at least 3 tiers of models.

005 | Evaluation harness and demo - Create a benchmark evaluation suite with 10+ diverse tasks spanning: math reasoning, web research, code generation, and multi-step planning. Implement automated scoring (exact match + LLM-as-judge). Run the full AOrchestra pipeline against a naive single-agent baseline and a static-roles baseline. Generate comparison metrics (accuracy, cost, latency, number of delegations). Output results as JSON + markdown report.
